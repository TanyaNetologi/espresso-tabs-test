# Автоматизация UI-тестирования Android-приложения: Espresso

## Описание проекта

Проект по автоматизации тестирования пользовательского интерфейса Android-приложения с использованием Espresso.

Цель проекта: реализация автоматизированных проверок основных элементов интерфейса и функциональности переключения вкладок приложения.

## Используемые технологии

- Java — язык программирования.
- Android Studio — среда разработки.
- Android SDK — инструменты разработки Android-приложений.
- Espresso 3.6.1 — библиотека для автоматизации UI-тестирования.
- JUnit 4 — организация и выполнение тестов.
- AndroidX Test — инструменты для инструментального тестирования.
- Hamcrest — создание условий поиска и проверки элементов интерфейса.
- Gradle — управление сборкой и зависимостями проекта.

## Объект тестирования

Android-приложение с интерфейсом на основе вкладок (Tabs) и компонентов ViewPager.

## Реализованные проверки

**1. Проверка главного экрана**

- Запуск MainActivity.
- Проверка отображения первой страницы.
- Проверка наличия текста `Page: 1`.

**2. Проверка переключения вкладок**

- Поиск второй вкладки по описанию `Tab 2`.
- Нажатие на вторую вкладку.
- Проверка перехода на вторую страницу.
- Проверка отображения текста `Page: 2`.

**3. Проверка контекста приложения**

- Получение контекста приложения через InstrumentationRegistry.
- Проверка соответствия имени пакета `com.netology.tabbedapplication`.

## Запуск тестов

1. Открыть проект в Android Studio.
2. Дождаться завершения синхронизации Gradle.
3. Запустить Android Emulator или подключить Android-устройство с включённой отладкой по USB.
4. Выполнить запуск инструментальных тестов.

Запуск всех инструментальных тестов через терминал:

**Windows:**

```powershell
.\gradlew.bat connectedAndroidTest
```

**Linux / macOS:**

```bash
./gradlew connectedAndroidTest
```
